# Action Rolls

Whenever you do something _difficult_, _dangerous_, or _dramatic_, you make and **action roll** to see how things go. To make an action roll, you roll between one and six <span class="keyword">d6</span> to read the **single highest result** to see if you get a <span class="keyword">hit</span>, <span class="keyword">snag</span>, or <span class="keyword">error</span>. In addition, if you roll any **doubles**—any two or more of the same number, a MESHnet <span class="keyword">glitch</span> occurs.

There are three different types of action rolls, but they all follow the same basic pattern for gathering a dice pool:

`Action (1d-3d) + Assets (0d-2d) + Variables (-1d or +1d)`

### Action Rolls Results

|                Roll                |               Result               | Effect              | Progress |
| :--------------------------------: | :--------------------------------: | ------------------- | :------: |
|  <span class="keyword">6+e</span>  | <span class="keyword">crit</span>  | Things go fantastic |    3     |
|   <span class="keyword">6</span>   |  <span class="keyword">hit</span>  | Things go great     |    2     |
|  <span class="keyword">4,5</span>  | <span class="keyword">snag</span>  | Things go okay      |    1     |
| <span class="keyword">1,2,3</span> | <span class="keyword">error</span> | Things go poorly    |    0     |

:::info Edge

Some assets, talents, and rules can give you _edge_ on rolls. When you have edge on a roll and the result is a <span class="keyword">hit</span>, upgrade it to a <span class="keyword">crit</span>.

:::

:::tip A Note on Glitches

You always follow the single highest result on the table of above, even when you get doubles. A roll of `[6,4,2,2]` would result in a `hit` with `crit`, for exmaple.

:::

### Encounter Rolls

Rolls during _encounters_ are made for individual PC actions and use your function ratings as the base trait. Encounter rolls can result in _consequences_ whose severity is based on the _risk_ of the roll. Consquences can be anything from a lost item, to a physical injury, to fatigue. See [Encounter Actions](#).

### Organizing Rolls

Rolls for community _organizing actions_ are made for the enclave as whole and use the enclave's _aspects_ as the base trait. Organizing rolls can result in major and minor _trouble_, such as natural disasters, internal social conflict, and, in the worst cases, raids by Dominion forces. See [Organizing Actions](#).

### Downtime Rolls

Rolls for _downtime actions_ are doen in relative safety. Crafting, recovery, research, and more can be done during downtime the rolls reflect how much progress you make, but without risk of consquences. See [Downtime Actions](#).
